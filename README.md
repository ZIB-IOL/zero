# Zero

Results accompanying **Zero: Programming Long-Horizon Mathematical Research Across Agents and Tools** by Nico Pelleriti, Konrad Plato, Max Zimmer, and Sebastian Pokutta.

The [supplementary material](supplementary_material/constructions/README.md) contains the packing and coloring constructions reported in the paper, together with verification code. See the [verification instructions](supplementary_material/constructions/EVALUATION.md).

The remaining code and artifacts are coming soon.
