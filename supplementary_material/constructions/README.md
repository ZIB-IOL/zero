# Supplementary constructions

This bundle contains the packing and coloring constructions reported in the paper and compact verification code.

- `rectangle_packing/`: 31 rectangle, cuboid, equilateral-triangle, and tetrahedron packings.
- `colorings/almost5/`: the periodic almost-five-coloring with removed fraction `136749079/3923609600`.
- `colorings/almost14/`: the periodic almost-14-coloring with removed fraction `31307/1577088`.
- `colorings/offdiagonal6/`: the five fixed periodic six-colorings used to certify the reported interval.

Each subdirectory contains its own verification instructions. Search histories, solver logs, intermediate candidates, repository metadata, local paths, and model transcripts are intentionally excluded.
